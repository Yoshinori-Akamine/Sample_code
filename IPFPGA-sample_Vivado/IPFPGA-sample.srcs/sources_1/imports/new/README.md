# サンプルファイルいれば
このファイルをコピペした上で、必要事項を加筆・修正して利用する目的

# ファイルの説明
- .vhdで終わるファイル：VHDLファイル
  - io_top.vhd、pwm_if.vhd：多分変更が加えられてないサンプルファイル
  - その他：流石にこっちはサンプルファイルのままだと思う
  - pwm_if_edited.vhd：85k フルパルス用に変えた。PDMはこれに書き加える形でいいと思う
- Default.c
  - PE_expert4で使うホストプログラム用のを自分で作った
  - 元々ホストプログラムにはサンプルファイルは存在しないと思う

# Vivadoで新たにプロジェクトを作るときの手順（以下予想。忘れたので後で追記する）
1. 新規プロジェクトを作る
2. 名前をつけて保存
3. 自分のコードを貼り付ける（大体はio_top.vhdとpwm_if.vhdだと思う）
4. 終わり。やってみてエラーが出たらデバッグ
